Extraia o AV2.zip para uma pasta do seu computador.

Abra a pasta VotacaoFazenda que foi extraída.

Abra essa pasta no VS Code e acesse o terminal integrado, pelo menu Terminal → Novo Terminal.

Execute o comando abaixo para instalar as dependências:

bash     npm install     

Depois, inicie a aplicação:

bash     npm run dev     

Abra no navegador o endereço http://localhost:5173/.
